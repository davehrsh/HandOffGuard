## 2026-11-13 — First working milestone

AI-assisted implementation: Java domain engine, isolated fake transport, local HTTP service, evidence dashboard, optional Spring adapter, normalized TSV CLI and CI workflow.

Design review decisions:
- Require receiving-side evidence; a fluent transfer promise cannot pass a test.
- Explicit SIMULATOR labels in UI and JSON prevent confusion with live customer data.
- Human acceptance, correct routing, context and idempotency are independently checked.
- Session filtering blocks unrelated conversation evidence from producing a pass.
- Render untrusted strings via textContent; no remote scripts, fonts or secrets in UI.
- Loopback binding for development server; no public deployment implied.
